# BUG-004 扩展打包脚本因找不到 pwsh 而失败

- 状态: closed
- 严重程度: S2 严重
- 发现时间: 2026-08-16 20:13 +08:00
- 发现人: edge-page-ai 开发
- 处理人: edge-page-ai 开发
- 发现环境: Windows 11 / npm 10 / PowerShell 5.1（无 pwsh 7 的 PATH 项）
- 关联功能/文件: `package.json`、`scripts/build-edge-bridge.ps1`

## 现象描述

执行 `npm run build:edge-bridge` 失败，cmd 报告
`'pwsh' is not recognized as an internal or external command`。

## 复现步骤

1. 在未安装（或 PATH 中不存在）pwsh 7 的 Windows 上执行 `npm run build:edge-bridge`。
2. 观察输出。

## 实际结果

打包脚本未执行，`dist/edge-bridge.zip` 未生成。

## 期望结果

使用系统自带的 Windows PowerShell 5.1 完成打包。

## 原因分析

npm 在 Windows 下通过 cmd 执行脚本，环境 PATH 中只有
`C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe`，没有 `pwsh`。

## 修复方案

将 npm 脚本改为
`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-edge-bridge.ps1`，
脚本内注释同步更新。
