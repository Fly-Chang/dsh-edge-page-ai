# BUG-001 测试脚本无法发现测试目录

- 状态: closed
- 严重程度: S1 阻断
- 发现时间: 2026-08-16 20:05 +08:00
- 发现人: edge-page-ai 开发
- 处理人: edge-page-ai 开发
- 发现环境: Windows 11 / Node v22.19.0 / edge-page-ai 0.1.0-dev
- 关联功能/文件: `package.json`、`tests/`

## 现象描述

执行 `npm test`（脚本为 `node --test tests/`）时，Node 将 `tests/` 当作模块入口加载，
报 `Cannot find module 'F:\AI_worker\Edge-page-ai\tests'`，测试套件完全无法启动。

## 复现步骤

1. 在项目根目录执行 `npm test`。
2. 观察输出。

## 实际结果

测试进程以 `MODULE_NOT_FOUND` 退出，未执行任何测试用例。

## 期望结果

自动发现 `tests/**/*.test.js` 并执行全部用例。

## 原因分析

Node 22 的测试运行器需要 glob 参数；直接传目录路径被当作普通模块入口解析。

## 修复方案

将测试脚本改为 `node --test "tests/**/*.test.js"`，由 Node 内部 glob 展开，兼容 Windows cmd 环境。
