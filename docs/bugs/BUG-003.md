# BUG-003 页面客户端模块与依赖静态路由全部返回 404

- 状态: closed
- 严重程度: S1 阻断
- 发现时间: 2026-08-16 20:09 +08:00
- 发现人: edge-page-ai 开发
- 处理人: edge-page-ai 开发
- 发现环境: Windows 11 / Node v22.19.0 / edge-page-ai 0.1.0-dev
- 关联功能/文件: `src/gateway/app.js`

## 现象描述

集成测试中 `GET /v1/client.mjs`、`/core/page-translator.js`、`/shared/gateway-client.js`
均返回 404，导致书签模式无法加载页面客户端。

## 复现步骤

1. 以 mock 配置启动网关（`createGatewayServer`）。
2. `GET http://127.0.0.1:<port>/v1/client.mjs`。
3. 观察响应。

## 实际结果

返回 `{ "error": { "code": "NOT_FOUND" } }`，而非 JavaScript 源码。

## 期望结果

返回对应源码文件，`Content-Type: text/javascript`，带 CORS 头。

## 原因分析

`app.js` 从 `node:fs` 引入了回调版 `readFile`，却按 Promise 风格 `await readFile(path, 'utf8')`
调用。回调版在缺少 callback 参数时同步抛出 `ERR_INVALID_ARG_TYPE`，被 catch 后置为 404。

## 修复方案

- 从 `node:fs/promises` 引入 Promise 版 `readFile`；
- 将 `/v1/client.mjs` 的读取与静态路由统一为“读取内容后返回”的逻辑。
