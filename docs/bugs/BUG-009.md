# BUG-009 还原原文后再次点击整页翻译无效

- 状态: resolved
- 严重程度: S1 阻断
- 发现时间: 2026-08-16 21:06 +08:00
- 发现人: 用户实测反馈
- 处理人: edge-page-ai 开发
- 发现环境: Windows 11 / Edge 151 / edge-page-ai 0.1.0-dev
- 关联功能/文件: `src/core/page-translator.js`、`src/core/text-collector.js`

## 现象描述

点击「整页翻译」→ 点击「还原原文」→ 再次点击「整页翻译」时，页面没有任何变化，
必须刷新页面后才能再次翻译。

## 复现步骤

1. 在示例页打开面板，点击「整页翻译」，正文出现 `【译】...`。
2. 点击「还原原文」，正文恢复英文。
3. 不刷新页面，再次点击「整页翻译」。

## 实际结果

第二次点击无效果，正文保持英文。

## 期望结果

第二次点击应重新收集文本并再次翻译。

## 原因分析

1. 首次翻译成功后 `applyTranslations` 会在文本节点的父元素上写
   `data-dsh-tr="1"`，防止后续重复翻译。
2. 「还原原文」只把 `node.nodeValue` 还原，**没有清除父元素上的 `data-dsh-tr` 标记**。
3. 再次翻译时 `collectTextUnits` 因祖先带 `data-dsh-tr` 跳过全部节点，
   收集结果为空，于是没有任何反应。

## 修复方案

1. `snapshotOriginals` 额外记录每个文本单元的父元素。
2. `restoreOriginals` 还原文本后，清除所有相关父元素的 `data-dsh-tr` 标记。
3. 新增 `tests/core/page-translator.test.js`：
   - 快照记录节点与父元素；
   - 还原原文并清除 `data-dsh-tr`；
   - 还原后收集前置条件满足。
4. 更新全量测试用例数（21/21）。
