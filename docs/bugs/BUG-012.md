# BUG-012 静默启动脚本在端口被占用时仍提示启动成功，用户误判无法启动

- 状态: resolved
- 严重程度: S2 严重
- 发现时间: 2026-08-16 22:00 +08:00
- 发现人: 用户实测反馈
- 处理人: edge-page-ai 开发
- 发现环境: Windows 11 / Edge 151 / edge-page-ai 0.1.0-dev
- 关联功能/文件: `scripts/start-gateway-silent.vbs`、`scripts/start-gateway.bat`、`scripts/check-gateway-running.mjs`

## 现象描述

双击桌面「DSH 翻译网关」后弹出：

```text
edge-page-ai gateway started in background.
Log file: F:\AI_worker\Edge-page-ai\logs\gateway.log
```

用户据此认为“无法启动/出现问题”。实际日志显示端口已被占用：

```text
[edge-page-ai] failed to start: listen EADDRINUSE: address already in use 127.0.0.1:8787
```

## 复现步骤

1. 网关已在 8787 端口运行。
2. 再次双击 `start-gateway-silent.vbs`。
3. 观察弹窗与 `logs\gateway.log`。

## 实际结果

第二个 node 进程因 EADDRINUSE 启动失败，但脚本仍无条件弹出“started in background”，
提示与真实状态相反。

## 期望结果

- 已运行时：明确提示“already running”，不要重复启动；
- 启动失败时：显示失败弹窗并指向日志；
- 启动成功时：显示成功弹窗。

## 原因分析

VBS 脚本 `shell.Run cmd, 0, False` 是异步启动，不等待也不检查 node 进程是否真正
监听成功，随后无条件弹成功框。重复启动时 EADDRINUSE 只写入日志。

## 修复方案

1. 新增 `scripts/check-gateway-running.mjs`：调用 `/v1/health`，退出码 0 表示运行中。
2. VBS 启动前先检查：已运行 → 弹“OK: already running”并退出，不再重复启动。
3. 未运行时启动 node，等待 2 秒后再次健康检查：成功 → OK；失败 → ERROR + 日志路径。
4. 前台 `start-gateway.bat` 同样先检查，已运行时提示无需操作并退出。
