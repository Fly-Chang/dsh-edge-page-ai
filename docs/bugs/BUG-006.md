# BUG-006 书签说明页导致用户收藏了说明页地址而非书签代码

- 状态: resolved
- 严重程度: S2 严重
- 发现时间: 2026-08-16 20:29 +08:00
- 发现人: 用户实测反馈
- 处理人: edge-page-ai 开发
- 发现环境: Windows 11 / Edge / edge-page-ai 0.1.0-dev
- 关联功能/文件: `src/gateway/app.js`、`docs/testing-guide.md`、`tests/gateway/server.test.js`

## 现象描述

用户在英文测试页点击刚创建的书签后，页面直接跳转到
`http://127.0.0.1:8787/v1/bookmarklet?token=<token>` 说明页，而不是在测试页出现
「DSH 页面助手」面板。

## 复现步骤

1. 启动网关，打开 `/v1/bookmarklet?token=<token>`。
2. 按旧版页面提示手动创建收藏夹，并把文本框中的代码填入收藏夹地址。
3. 在英文页面点击该收藏夹。

## 实际结果

浏览器导航到书签说明页，测试页无面板。

## 期望结果

点击书签后，当前页面出现面板，不发生任何跳转。

## 原因分析

1. 旧版文本框里的代码**缺少 `javascript:` 前缀**，只给了
   `(()=>{...})();`。粘贴到收藏夹地址栏时浏览器不会把它识别为 bookmarklet。
2. 页面没有警告“不要用 `Ctrl+D` 收藏本说明页”。用户若收藏的是说明页，点击书签就会
   跳到说明页，与反馈现象完全一致。
3. 因此这是说明页文案/交互缺陷，不是网关或注入脚本缺陷。

## 修复方案

1. 文本框内容与「复制书签代码」按钮均提供完整 `javascript:(()=>{...})();` 地址。
2. 说明页顶部增加红色警示：地址必须 `javascript:` 开头，出现跳转到
   `/v1/bookmarklet` 即代表收藏错对象。
3. 增加“方式 A 拖拽 / 方式 B 复制代码后编辑收藏夹”两种明确路径。
4. 测试指南同步更新，并要求右键检查收藏夹地址前缀。
5. 新增自动化断言：说明页包含 `javascript:` 前缀代码、复制按钮与常见错误提示。
