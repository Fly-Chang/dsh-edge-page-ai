# BUG-016 扩展重载/旧页面场景点击图标偶发调不出面板，且失败无可见提示

- 状态: resolved
- 严重程度: S1 阻断
- 发现时间: 2026-08-16 22:55 +08:00
- 发现人: 用户实测反馈
- 处理人: edge-page-ai 开发
- 发现环境: Windows 11 / Edge 151 / edge-page-ai 0.1.0-dev
- 关联功能/文件: `src/edge-bridge/background.js`、`content.js`

## 现象描述

扩展更新后，用户点击工具栏图标或快捷键，面板不出现，也没有任何错误提示。

## 复现步骤

1. 多次重载扩展，或页面在扩展重载前已打开。
2. 点击扩展图标。

## 实际结果

无面板、无提示（旧版本只在 sendMessage 失败时补救注入，且失败被静默吞掉）。

## 期望结果

点击后要么出现面板，要么在页面/图标上有明确错误提示。

## 原因分析

1. 旧逻辑仅在 `chrome.tabs.sendMessage` 抛错时才用 `chrome.scripting` 注入；
   部分旧页面/旧上下文场景消息可达但面板初始化失败，表现为无反应。
2. 失败路径全部静默，用户无法区分“没点到”和“加载失败”。

## 修复方案

1. 后台每次点击都**先注入最新 content script**（content 有防重复守卫），再发送
   toggle 消息，彻底覆盖“页面在重载前打开”的情况。
2. toggle 失败时给扩展图标设置红色 `!` badge。
3. content script 初始化失败时，在页面右下角显示 8 秒可见错误提示
   “无法启动：请确认网关已运行，且扩展选项中已填写 token”。
4. 保持手动模式：页面加载不自动访问网关。
