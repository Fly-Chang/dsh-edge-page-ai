# 01 项目章程

- 文档编号: PM-01
- 版本: 1.0.0
- 状态: 生效
- 生效日期: 2026-08-16
- 维护人: 项目所有者

## 1. 项目名称

`edge-page-ai`（工作代号）。中文全称：Edge 页面 AI 翻译与随呼助手。

## 2. 项目目标

在 Edge 浏览器任意页面上可随时调出 DSH（或已配置模型），并对英文页面执行“整页翻译”，
要求只替换页面文字、尽量保持页面结构与版式不变。

## 3. 目标用户

1. 个人使用（本机本地部署）。
2. 小范围交流使用（开源社区分享，各用户自带模型配置）。

## 4. 产品形态

- 主体：DSH 插件（本地网关 + 翻译核心 + 对话/模型适配）。
- 浏览器侧：两种轻量入口，均不含业务智能：
  - 书签模式（bookmarklet，零安装，用于试用与小范围分享）。
  - Edge 薄壳桥接扩展（MV3，用于日常完整体验）。
- 所有业务智能（模型配置、翻译分段、占位符保护、缓存、术语库、对话）均位于 DSH 插件侧。

## 5. 范围（In Scope）

- 冻结的本地通信协议 v1（`/v1/*`）。
- 本地网关（仅监听 127.0.0.1，token 鉴权）。
- 翻译核心：文本节点级替换、块级分段、占位符保护、结构回填。
- 书签模式与 Edge 薄壳扩展。
- 配置导出/导入（个人换机场景）。
- 测试、文档、工作日志、缺陷记录。

## 6. 非目标（Out of Scope，当前版本不做）

- Edge 商店上架、云端多租户服务。
- 图片 OCR 翻译。
- 付费/许可体系。
- 对 `edge://*`、扩展商店等浏览器保留页面的支持。

## 7. 成功标准（MVP 验收）

1. `npm start` 后本地网关启动，`GET /v1/health` 返回协议版本。
2. 书签模式可在普通英文页面完成整页翻译，DOM 结构与交互不丢失。
3. 薄壳扩展可注入悬浮按钮，转发至本地网关完成翻译。
4. 全部单元测试通过。
5. 工作日志、缺陷记录按本规范持续更新。

## 8. 决策记录（ADR，随变更追加）

| 日期 | 决策 | 理由 |
| --- | --- | --- |
| 2026-08-16 | 主体做成 DSH 插件，浏览器侧仅保留薄壳/书签 | 符合开源社区定位；降低浏览器侧维护成本 |
| 2026-08-16 | 冻结 `gateway-protocol-v1`，扩展只依赖该协议 | DSH 更新不影响浏览器侧；可独立演进 |
| 2026-08-16 | 默认 BYOK（OpenAI 兼容端点） | 个人/小范围场景下不共享密钥 |
